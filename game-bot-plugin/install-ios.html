Option A — Bookmarklet No app needed

Step 2 — Save as a bookmark on iOS Safari

1Bookmark any page first (tap the share icon → Add Bookmark).
2Open Bookmarks (⎙ icon → Bookmarks tab).
3Edit the bookmark you just created. Change its name to Runner Bot.
4Delete the URL field completely, then paste the copied code.
5Tap Done.
On desktop Safari / Chrome you can drag the bookmarklet link directly to your bookmarks bar — no editing needed.

Step 3 — Use the bot

1Open icemancountdown.com/runner in Safari.
2Tap your bookmarks, then tap Runner Bot.
3A control bar appears at the bottom of the screen. Tap ▶ Start.
4The bot plays forever. Tap ■ Stop or close the tab to stop it.

Option B — Userscript Recommended for iOS

Auto-runs every time you open the game — no bookmarklet tap needed. Requires the free Userscripts app (iOS / iPadOS).

Step 1 — Install the Userscripts app

Search "Userscripts" on the App Store (by Justin Wasack, free & open-source).
Or: apps.apple.com/app/userscripts/id1463298887

Step 2 — Enable the Safari Extension

1Go to Settings → Safari → Extensions.
2Enable Userscripts and grant permission for all websites (or just icemancountdown.com).

Step 3 — Add the script

1Open the Userscripts app.
2Tap + → New script.
3Delete the placeholder text and paste the contents of userscript.js from this folder.
4Save. The script is now active on icemancountdown.com/runner.
The panel appears automatically when you open the game. Tap ▶ Start to begin. You only need to set this up once — it persists across sessions.

Chrome / Edge / Brave

How the bot works

  • 60 fps rAF scan loop — reads a vertical slice of canvas pixels every frame
  • Two obstacle zones — ground zone triggers Jump, air zone triggers Duck
  • Adaptive scan distance — scan columns shift right every 30 s as the game speeds up
  • Air-time guard — won't re-jump while already airborne (avoids wasted jumps)
  • Rhythm fallback — if canvas pixel reads are blocked (iOS security), uses an auto-adaptive timed jump rhythm instead
  • Direct game hook — probes window.game, window.runner, etc. to call .jump() / .duck() natively
  • Touch + keyboard + pointer events — all three input types fired simultaneously
  • Auto-restart — detects game-over by canvas freeze and restarts automatically
  • Background recalibration — resamples sky colour every 8 s to handle palette shifts
